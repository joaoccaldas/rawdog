# Rawdog

**2D Survival Game**

A 2 survival game built with JavaScript. Gather resources, craft tools, fight enemies, and survive.

## Features
- Resource gathering and crafting
- Enemy combat system
- Tool and inventory management
- Procedurally generated world

## Status
Complete. Built as a survival gaming experiment.

*"Built by João Caldas | joaoccaldas@gmail.com"*

## Lineage

This repository is the earlier 2D Rawdog survival-game experiment. The later 3D lineage lives separately in `rawdogging`; this repository is useful as a record of the earlier design and implementation ideas rather than a duplicate of the 3D project.
